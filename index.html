L'écosystème Web

1. Définition

L'écosystème Web est composé de plusieurs technologies. Chacune a un role bien défini. HTML pour déposer et structurer les objets graphiques, CSS pour mettre en forme ces derniers, et JavaScript pour ajouter l'interaction homme/machine. Ce sont des langages indisponsables pour commencer à apprendre les frameworks tels que: Angular, React et Vu.js. Le dévéloppement Front-End nécéssite des compétences fortes en tout ce qui est langages natifs.
