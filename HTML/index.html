L'écosystème Web

1. Définition

Le Web est un ensemble de technologies qui permettent de créer des sites web et des applications web. Il est basé sur le protocole HTTP et utilise le langage HTML pour structurer les pages web. Le Web est également composé de plusieurs autres technologies telles que CSS, JavaScript, PHP, etc.
